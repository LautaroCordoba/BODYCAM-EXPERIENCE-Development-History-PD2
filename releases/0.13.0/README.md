## Controls

### BODYCAM - Recargar y cambiar perfil

Recarga y valida tuning.lua, luego cambia al siguiente perfil BODYCAM.

**Keybind:** `bodycam_switch_mode`

### BODYCAM - Movimiento ON/OFF

Activa o desactiva FreeAim y la inercia BODYCAM.

**Keybind:** `bodycam_toggle_freeaim`

Keybinds can be changed from PAYDAY 2's keybind settings.
