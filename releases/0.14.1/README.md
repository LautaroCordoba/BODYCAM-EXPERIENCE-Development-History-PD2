## Controls

### BODYCAM - Comparar vista

Alterna Bodycam y Vanilla. Conserva el preset y reinicia FreeAim para comparar desde el centro.

**Keybind:** `bodycam_compare_view`

### BODYCAM - Recargar y cambiar perfil

Recarga y valida tuning.lua, luego cambia al siguiente perfil BODYCAM.

**Keybind:** `bodycam_switch_mode`

### BODYCAM - FreeAim ON/OFF

Activa o desactiva solo FreeAim; conserva la inercia del preset.

**Keybind:** `bodycam_toggle_freeaim`

Keybinds can be changed from PAYDAY 2's keybind settings.
