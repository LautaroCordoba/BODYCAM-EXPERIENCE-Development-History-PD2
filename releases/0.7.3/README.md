## Controls

### BODYCAM - Cambiar movimiento

Cambia entre perfiles de movimiento.

**Keybind:** `bodycam_switch_mode`

### BODYCAM - Recargar tuning

Recarga tuning.lua sin reiniciar PAYDAY 2.

**Keybind:** `bodycam_reload_tuning`

### BODYCAM - Activar/Desactivar Free Aim

Activa o desactiva el Free Aim experimental.

**Keybind:** `bodycam_toggle_freeaim`

### BODYCAM - Inspeccionar Rig

Registra informacion del rig FPS y del arma.

**Keybind:** `bodycam_inspect_rig`

Keybinds can be changed from PAYDAY 2's keybind settings.
