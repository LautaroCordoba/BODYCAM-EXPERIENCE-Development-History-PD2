## Controls

### BODYCAM - Cambiar perfil

Cambia el perfil BODYCAM.

**Keybind:** `bodycam_switch_mode`

### BODYCAM - Recargar tuning

Recarga tuning.lua.

**Keybind:** `bodycam_reload_tuning`

### BODYCAM - Free Aim ON/OFF

Activa o desactiva BODYCAM Free Aim.

**Keybind:** `bodycam_toggle_freeaim`

Keybinds can be changed from PAYDAY 2's keybind settings.
